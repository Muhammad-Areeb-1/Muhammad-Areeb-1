## Featured projects

### [Veritrace](https://github.com/Muhammad-Areeb-1/REPO-NAME) · Final year project
Pipeline and scoring engine for monitoring how misinformation spreads on Twitter/X: real-time data collection, claim clustering, and BERT-based risk scoring across content, source credibility and propagation patterns. Reached 65–75% classification accuracy on a self-curated, Pakistan-specific test set (no standard benchmark existed for it, so treat that number as self-tested).
`Python` `Transformers` `FastAPI` `React`

### [T20 Score Predictor](https://github.com/Muhammad-Areeb-1/REPO-NAME)
Predicts the final score of a T20 cricket innings from ball-by-ball match state. Features include rolling run/wicket windows and Powerplay/Middle/Death phase signals. Historical baselines are computed on the training set only to prevent leakage, and categorical features were checked with Chi-square and Cramér's V. Best model (Gradient Boosting) reached **16.63 MAE and 0.718 R²** on held-out matches, ahead of Linear Regression and Random Forest.
`Python` `scikit-learn` `Pandas` `NumPy`

### [Chibi Coin](https://github.com/Muhammad-Areeb-1/REPO-NAME)
Personal finance backend: multi-category expense tracking, budget limits, savings goals, currency conversion, push notifications (FCM) and receipt storage via the Google Drive API. API integration tests with Jest and Supertest (55% statement coverage).
